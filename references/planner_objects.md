# Объекты онлайн-планировщика (экспорт GLB через THREE.GLTFExporter)

Имя: `тип|objN|_экземпляр[|handle]`. `L.parse(name)` → (тип, objN, имя). Часть `objN` — конкретная деталь;
номера стабильны внутри типа. Ниже — что видели на практике (проверяй по `parts.txt`: габарит, число вершин,
цвет каждой детали). Имена материалов в экспорте обычно бессмысленные (`Material_N`) — опирайся на детали.
Детали по 4–24 вершины с нулевым габаритом — служебные точки, их можно скрыть.

| Тип | Что это | Детали |
|---|---|---|
| `wall|R_<комната>|_<id>|sN` | грань стены, обращённая в комнату `R_<id>` | `parse()` вернёт `R_<id>` второй частью; бывают двойные экземпляры `|_i1do9|_mxc44|`; комнату определяй по полу `floor|_<id>` с тем же id |
| `floor|_<id>` | пол комнаты | плита со скруглёнными кромками (~800 граней), не плоскость; в открытой планировке (студия) один пол на кухню, гостиную, спальню-нишу и прихожую — зоны делит мебель или штора (см. список полов в `objects.txt`) |
| `CapUpper*`, `FacadeWall` | верхние заглушки стен, внешний контур дома | на плане/изометрии скрывать |
| `portal|_<id>` | откосы проёмов | красить как стены |
| `french_window` | окно/дверь в пол | `glass` — стекло, остальное — рама (чёрная) |
| `door`, `door_coupe`, `doorPlateA/B` | входная, раздвижная двери, наличники | `door obj2` — филёнки (скрыть для гладкой двери) |
| `ward` | шкаф | obj1/obj10 — фасады, obj2 — корпус; obj3..8 — служебные точки по 4 вершины (не ручки); ручки — `…|handle` |
| `facade_door` | дверца шкафа-ниши (например, бойлерной) | `…|handle` — ручка |
| `mezzanine_cabinet_2door` | антресоль | obj1 корпус, obj2 фасад, obj3 ручка |
| `kitchen_box_door_double`, `_dishwasher` | нижние модули кухни | obj1 корпус, obj2/obj10 фасады, obj3 столешница, obj5 цоколь |
| `kitchen_box_wall_double` | верхние модули | obj1 корпус, obj10/obj11 фасады |
| `built_in_fridge`, `kitchen_box_penal` | колонны | фасады obj10/11/12, obj3 — корпус, obj2 — цоколь |
| `pencil_case_oven_microwave` | колонна с духовкой и микроволновкой | obj4 корпус, obj11 нижний фасад (+ `|box` ящик), obj12 верхний фасад, obj17 рамка микроволновки, obj7 цоколь; экземпляры с суффиксом `.001…006` (`_vqr2r.002`) и чёрный obj10 — сама техника, не трогать |
| `kitchen_island_stand` | остров/барная стойка (одним мешем) | |
| `bar_chair_backrest` | барный стул | obj1 сиденье со спинкой (обивка), obj2 каркас и ножки, obj3 точка |
| `bed_double` | кровать | obj11 каркас с изголовьем, obj10 основание, obj2 одеяло (нижние 2/3), obj4 подушки, obj5 простыня; obj1/3/6/12 — точки (скрыть) |
| `cradle` | детская кроватка | obj1 каркас, obj2 матрас, obj3 бельё |
| `beauty_table` | туалетный столик | obj1 зеркало, obj3 корпус, obj5 столешница |
| `pouf-cube` | пуф | obj1 обивка, obj2 основание |
| `tv_table`, `tv_legs` | ТВ-тумба, телевизор на стене | у `tv_legs` obj1 — экран |
| `sofa_triple` | диван | obj1/obj4 обивка |
| `wall_curtains` | штора от стены до стены | obj1/obj2 полотна, obj3 карниз, obj4..7 точки |
| `sink_box_floor` | тумба с раковиной | obj1 фасад, obj4 корпус, obj3 раковина, obj2 смеситель, obj5 цоколь, obj6 ручка |
| `toilet_with_frame`, `shower_screen`, `square_tray`, `hidden_shower_system` | сантехника | |
| `pencil_cabinet_above_washing`, `washing_machine` | шкаф над стиралкой, стиралка | |
| `convector_on_floor` | напольный конвектор | часто заменяют встроенным в пол |
| `water_column_*` | стояки | обычно скрывают (зашиты в короб) |
| `gas_pipe` | газовая труба от пола до потолка (жёлтая) | красить в цвет стены |
| `boiler`, `airbox` | котёл, вентиляционный короб | |
| `socket*`, `Mesh_*` | розетки | не трогать |
| любое `...|handle` | ручка | скрыть для фасадов без ручек |

Подсказки:
- Все фасады `ward/kitchen_*/mezzanine` в каталоге рамочные — для современного стиля `flatten_front`.
- Потолка в экспорте нет — `L.ceilings_from_floors(meshes, H, "ceiling")` строит его по точным контурам полов.
  Отдельный потолок (другая высота, ниша) — `plane(..., down=True)`, без перекрытий с соседними.
- Лоджия часто экспортируется с парапетом 1 м без остекления и без потолка — уточни у пользователя, как на самом деле.
