# Объекты онлайн-планировщика (экспорт GLB через THREE.GLTFExporter)

Имя: `тип|objN|_экземпляр[|handle]`. `L.parse(name)` → (тип, objN, имя). Часть `objN` — конкретная деталь;
номера стабильны внутри типа. Ниже — что видели на практике (проверяй по `objects.txt` и габаритам).

| Тип | Что это | Детали |
|---|---|---|
| `wall|R_<комната>|_<id>|sN` | грань стены, обращённая в комнату `R_<id>` | комнату определяй по полу `floor|_<id>` с тем же id |
| `floor|_<id>` | пол комнаты | |
| `CapUpper*`, `FacadeWall` | верхние заглушки стен, внешний контур дома | на плане/изометрии скрывать |
| `portal|_<id>` | откосы проёмов | красить как стены |
| `french_window` | окно/дверь в пол | `glass` — стекло, остальное — рама (чёрная) |
| `door`, `door_coupe`, `doorPlateA/B` | входная, раздвижная двери, наличники | `door obj2` — филёнки (скрыть для гладкой двери) |
| `ward` | шкаф | obj1/obj10 — фасады, obj2 — корпус, obj3..8 — ручки |
| `mezzanine_cabinet_2door` | антресоль | obj1 корпус, obj2 фасад, obj3 ручка |
| `kitchen_box_door_double`, `_dishwasher` | нижние модули кухни | obj1 корпус, obj2/obj10 фасады, obj3 столешница, obj5 цоколь |
| `kitchen_box_wall_double` | верхние модули | obj1 корпус, obj10/obj11 фасады |
| `built_in_fridge`, `kitchen_box_penal`, `pencil_case_oven_microwave` | колонны | фасады obj10/11/12; материалы `default_*` — сама техника, не трогать |
| `kitchen_island_stand` | остров/барная стойка (одним мешем) | |
| `bar_chair_backrest` | барный стул | obj1 обивка, obj2 каркас |
| `bed_double` | кровать | obj11/obj10 каркас+изголовье, obj2 плед, obj4 подушки, obj5 простыня |
| `sofa_triple` | диван | obj1/obj4 обивка |
| `wall_curtains` | штора от стены до стены | obj1/obj2 полотна, obj3 карниз |
| `sink_box_floor` | тумба с раковиной | obj1 фасад, obj4 корпус, obj3 раковина, obj2 смеситель, obj5 цоколь, obj6 ручка |
| `toilet_with_frame`, `shower_screen`, `square_tray`, `hidden_shower_system` | сантехника | |
| `pencil_cabinet_above_washing`, `washing_machine` | шкаф над стиралкой, стиралка | |
| `convector_on_floor` | напольный конвектор | часто заменяют встроенным в пол |
| `water_column_*` | стояки | обычно скрывают (зашиты в короб) |
| `socket*`, `Mesh_*` | розетки | не трогать |
| любое `...|handle` | ручка | скрыть для фасадов без ручек |

Подсказки:
- Все фасады `ward/kitchen_*/mezzanine` в каталоге рамочные — для современного стиля `flatten_front`.
- Потолка в экспорте нет — добавляй плоскостями `plane(..., down=True)` по контурам комнат, без перекрытий.
- Лоджия часто экспортируется с парапетом 1 м без остекления и без потолка — уточни у пользователя, как на самом деле.
