# Материалы

Все цвета в `scene_lib` — линейные. Цвет образца из картинки (sRGB) переводи `L.srgb_to_linear()`.
Белые фасады и стены не делай чисто белыми: тёплый белый (0.78–0.83, 0.75–0.80, 0.70–0.74) выглядит как на
дизайнерских рендерах; чистый белый пересвечивается.

## Poly Haven (CC0, без регистрации)
- Список: `curl https://api.polyhaven.com/assets?t=textures` (или `t=models`).
- Файлы и размеры: `curl https://api.polyhaven.com/files/<id>` → `Diffuse/nor_gl/Rough → 2k → jpg → url, size`.
- Реальный размер текстуры (для `size_m`): `curl https://api.polyhaven.com/info/<id>` → `dimensions` (мм).
- Превью для выбора: `https://cdn.polyhaven.com/asset_img/thumbs/<id>.png?width=200&height=200` — смотреть
  можно без спроса; собрать несколько в один лист и выбрать глазами.
- Перед скачиванием — таблица пользователю: id, для чего, размер в МБ. Кладём в `<проект>/textures/` и `assets/<id>/`.
- Проверенные: `oak_veneer_01` (шпон дуба, 1.83 м), `wood_floor` (паркет, 1.7 м), `rough_linen` (лён, 0.27 м),
  `marble_01` (бежевый камень с запечённой раскладкой — для плитки точного размера не годится, лучше `tiles()`).
  Модели: `potted_plant_02`, `pachira_aquatica_01`, `calathea_orbifolia_01`, `anthurium_botany_01` (варианты a–f
  в одном файле — выбирай префиксом в `import_asset(keep=[...])`), `ceiling_fan`.

## Цвет по образцу из каталога (шпон, панели)
1. Средний sRGB образца (без рамки и подписи) и средний sRGB текстуры:
   ```python
   im = bpy.data.images.load(p); px = im.pixels[:]   # значения в sRGB для 8-битных картинок
   ```
   (или Pillow: `ImageStat.Stat(img).mean / 255`).
2. `tint = L.tint_for_swatch(swatch_mean, texture_mean)` → `L.textured(..., tint=tint)`.
   Так текстура сохраняет рисунок, а средний цвет совпадает с каталогом (пример: Дуб Небраска на `oak_veneer_01`
   → tint ≈ (1.52, 1.78, 2.12)).

## Ламинат/паркет из фото образца
1. Найди швы между рядами досок: средняя яркость по строкам — минимумы и есть швы.
2. Обрежь фото до ЦЕЛОГО числа рядов (иначе на стыке повторов появится доска двойной ширины), сохрани PNG.
3. `L.photo_planks(name, png, tile_u, tile_v, along="Y")`: `tile_v = рядов × ширина доски` (обычно 0.19–0.2 м),
   `tile_u = tile_v × ширина_фото / высота_фото`. Торцевые стыки на краю фото выглядят как обычные стыки досок.

## Плитка/панели заданного размера
`L.tiles(name, w, h, c1, c2, floor=False, offset=0.0, joint=0.002, veins=None)` — вертикальная плитка 60 × 120:
`w=0.6, h=1.2`; ряды со смещением (фасадные панели): `offset=0.5`; мрамор: `veins=(светлый цвет)`.
Раскладка стен начинается от пола, работает и для стен вдоль X, и вдоль Y. Для пола — отдельный материал `floor=True`.
Цвет в санузле: беж (0.68, 0.61, 0.52)/(0.62, 0.55, 0.46); тауп мрамор душа (0.36, 0.31, 0.27) + прожилки (0.62, 0.58, 0.53).

## Фотообои
`L.photo_wallpaper(name, path, x, y0, y1, z0, z1, img_left_y=None, img_bottom_z=0, img_h=None)` — во всю высоту
стены, правый край картинки у y1 (лишнее срезается слева). Сдвиг/подъём — через `img_left_y`/`img_bottom_z`;
за краями — продолжение краевых пикселей. Если пользователь просит «сдвинуть, чтобы были видны ноги» — покажи
пробный кадр: при подъёме изображения нижняя полоса картинки (пол) уходит за диван.

## Ткани и мягкая мебель
- Бархат: `solid(..., sheen=0.6, sheen_tint=...)`, цвет тауп (0.30, 0.25, 0.205).
- Кожа кремовая: `solid((0.58, 0.51, 0.42), 0.45, coat=0.15)`.
- Лён/постель: `textured("rough_linen", desat=1.8, tint=...)`; на складках штор текстура даёт рисунок — шторы однотонные.

## Металлы, стекло, свет
- Графит-шампань для сантехники: `solid((0.42, 0.38, 0.34), 0.32, metal=1)`; графит: (0.3, 0.29, 0.28).
- Зеркало: `solid((0.95,)*3, 0.0, metal=1)`; подсветка-контур — `stadium()` чуть больше зеркала с LED-эмиссией сзади.
- LED-лента: `emission((1, .78, .55), 12)`; лампочка в плафоне: `emission(..., 8)` + POINT-лампа 6–18 Вт.
- Окна/душ: `window_glass()`; плафоны: `glass()`; рифлёное: `fluted_glass()` (перегородка в плоскости YZ).

## Освещение интерьера (стартовые значения)
- Небо `sky_world()`, солнце `sun(3.5)`; споты на треках 35–45 Вт (угол 55°); бра 25 Вт; заполняющий свет
  под потолком 25–160 Вт по площади. AgX, look "Medium High Contrast", exposure 0.
- Если картинка «пересвечена и белая» — уменьши заполняющий свет вдвое, затемни белые на 3–5%.
