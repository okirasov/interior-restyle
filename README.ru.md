# interior-restyle

[English](README.md) · **Русский**

Скилл для [Claude Code](https://claude.com/claude-code). Берёт 3D-модель планировки квартиры (экспорт из
онлайн-планировщика) и картинки дизайна, который вам нравится, собирает квартиру в этом стиле в **Blender** и
выпускает визуализацию: рендеры по комнатам, PDF-презентацию и видео-проход по квартире.

С Claude вы говорите обычными словами: «примени этот дизайн к новой планировке», «сделай санузел как на этих
рендерах», «поменяй пол на этот ламинат из каталога», «сделай видео прохода». Скилл даёт Claude порядок работы,
проверенную библиотеку для Blender и решения для известных проблем Blender/Cycles. Поэтому результат
воспроизводим, а любую правку можно применить заново одной командой.

## Что умеет

- **Разбирает сцену.** Список всех объектов экспорта с габаритами, план сверху и изометрия; сопоставляет комнаты
  старого дизайна с новой планировкой.
- **Спрашивает до того, как строить.** Уточняющие вопросы по одному: можно ли двигать мебель или только менять
  отделку, перекрашивать или заменять предметы, откуда брать текстуры, что нужно на выходе.
- **Пересобирает квартиру в Blender** через проектный скрипт сборки, так что каждое решение записано в коде:
  - материалы из бесплатных текстур [Poly Haven](https://polyhaven.com) (CC0, скачиваются только после вашего «да»);
  - цвет по образцам из каталога поставщика (шпон, стеновые панели);
  - ламинат или паркет по фото образца из каталога, обрезанному до целых рядов досок;
  - плитка точного размера (например, вертикальная 60 × 120 см, прямая укладка или со смещением), мраморные прожилки;
  - фотообои на стене от колонны до колонны;
  - гладкие фасады без ручек вместо рамочных из каталога, встроенные ниши, ТВ-стена, открытые шторы,
    встроенные в пол конвекторы, душ без поддона с рифлёным стеклом, подвесная каменная раковина,
    LED-подсветка, трековые светильники.
- **Рендерит** в Cycles на видеокарте: сначала быстрый предпросмотр, потом финальные кадры. Санузел — вертикальными
  кадрами, плюс изометрия (со стороны окон и со стороны входа) и план сверху.
- **Экономно вносит правки.** После каждого изменения перерендеривает **только те кадры, где оно видно**,
  и перед долгим рендером называет время.
- **Собирает PDF:** обложка, разделы по комнатам, подпись с материалами под каждым кадром.
- **Делает видео-проход** по согласованному маршруту: плавная камера по сплайну с ограничением скорости шага и
  поворота головы, размытие в движении, сначала черновик в EEVEE, потом финал в Cycles.

## Что нужно

| | |
|---|---|
| Claude Code | скилл использует локальные программы (Blender, Python, ffmpeg), поэтому работает в Claude Code, а не в claude.ai |
| Blender 5.x | проверено на **5.2.2, macOS (Apple Silicon, Metal)**; команда `blender` должна быть в `PATH` |
| Python 3 + Pillow, reportlab | только для листов предпросмотра и PDF (Claude сам создаёт временное окружение) |
| ffmpeg | только для видео (`brew install ffmpeg`) |

## Установка

```bash
git clone https://github.com/okirasov/interior-restyle.git ~/.claude/skills/interior-restyle
```

Всё: Claude Code подхватывает скиллы из `~/.claude/skills/` в любом проекте. Обновление:
`git -C ~/.claude/skills/interior-restyle pull`.

## Как пользоваться

Положите файлы в папку проекта и откройте в ней Claude Code. Примеры запросов:

- «Вот новая планировка в 3D (`scene.glb`), а в `refs/` рендеры дизайна, сделанного под старую планировку.
  Примени этот дизайн к новой планировке. Задавай уточняющие вопросы».
- «Сделай пол этим ламинатом из каталога» *(приложите фото образца)*.
- «За диваном сделай фотообои от колонны до колонны» *(приложите картинку)*.
- «Плитка в ванной будет 120 см высотой и 60 см шириной».
- «Сделай санузел точно как на этих рендерах» *(приложите картинки)*.
- «Собери из готовых рендеров PDF».
- «Можно сделать видео прохода по квартире? Обсудим маршрут».

### Что дать на вход

| Вход | Обязательно? |
|---|---|
| 3D-сцена новой планировки (GLB/GLTF, FBX, OBJ или .blend), например экспорт из онлайн-планировщика | да |
| Референсы стиля: рендеры или фото дизайна | да |
| План старой квартиры (если референсы делались под другую планировку) | желательно |
| Образцы из каталога: пол, стеновые панели, плитка (с размерами) | по желанию |
| Фото или 3D-файлы конкретных товаров (диван, обои, сантехника) | по желанию |

### Опции, о которых спросит Claude

- **Расстановка:** не трогать / можно добавлять встроенную мебель / можно двигать.
- **Предметы:** перекрасить существующие / заменить детальными моделями (каждую согласует с вами).
- **Текстуры:** Poly Haven (с подтверждением) / только процедурные / ваши образцы из каталога.
- **Результат:** какие комнаты, PDF, видео (длительность, черновик или финал).
- **Качество:** см. таблицу ниже.

### Правила, встроенные в скилл

- Ничего не скачивается без вашего явного «да»: сначала Claude называет файл, источник, лицензию и размер.
- Ни один предмет не заменяется другой моделью без вашего согласия.
- Перерендериваются только затронутые кадры; про долгие рендеры Claude предупреждает и запускает их в фоне.
- Расстановка не меняется, если вы не разрешили.

## Как устроено

1. **Разбор**: `scripts/inspect_scene.py` выдаёт список объектов с габаритами и план; Claude изучает референсы
   и сопоставляет комнаты старой и новой планировки.
2. **Вопросы**: по одному, с опорой на найденное; итоговое описание вы одобряете.
3. **Пробные кадры**: стиль настраивается на 1–2 комнатах (предпросмотр → финал), пока вы не подтвердите.
4. **Все комнаты**: камеры для каждой комнаты, план и изометрия; предпросмотр листами, затем финал.
5. **Правки**: каждая правка вносится в проектный скрипт сборки; перерендер — только затронутых кадров.
6. **PDF**: `scripts/make_pdf.py` по небольшому JSON-описанию.
7. **Видео**: маршрут в JSON → `--analyze` (проверка скорости и поворотов) → контрольные кадры → черновик EEVEE → финал Cycles.

Сцену каждой квартиры собирает проектный скрипт (`<проект>/scripts/build_scene.py`), который Claude пишет на
основе общей библиотеки `scripts/scene_lib.py`. Координаты у каждой квартиры свои, а материалы, геометрия,
свет, камеры и настройки рендера общие.

## Структура репозитория

```
interior-restyle/
├── SKILL.md                  # порядок работы и правила для Claude
├── scripts/
│   ├── scene_lib.py          # библиотека для Blender: импорт, материалы, геометрия, свет, камеры, рендер
│   ├── inspect_scene.py      # объекты и детали с габаритами + план с сеткой и изометрия экспорта планировщика
│   ├── contact_sheet.py      # несколько рендеров на одной картинке для быстрого просмотра
│   ├── swatch.py             # средний цвет участков картинки (образец каталога, референс) для подбора материалов
│   ├── make_pdf.py           # PDF-презентация по JSON-описанию
│   └── walkthrough.py        # видео-проход с плавной камерой и ограничением скорости
├── references/
│   ├── pitfalls.md           # известные проблемы Blender 5.x / Cycles и их решения
│   ├── materials.md          # рецепты материалов, подгонка цвета под каталог, Poly Haven API
│   ├── planner_objects.md    # что означают имена объектов планировщика (фасады, ручки, корпуса)
│   └── video.md              # маршрут видео, плавность, время рендера
└── docs/images/              # картинки для этого описания
```

### Скрипты по отдельности

```bash
# разбор экспорта планировщика
blender -b --python scripts/inspect_scene.py -- scene.glb out_dir/

# лист предпросмотра / PDF (Python с Pillow + reportlab; всегда запускать с -I)
python -I scripts/contact_sheet.py sheet.jpg renders/*.png --cols 3
python -I scripts/swatch.py swatches.jpg ref.jpg 650 150 790 350 дуб --texture textures/oak_veneer_01_diff_2k.jpg
python -I scripts/make_pdf.py pdf_config.json renders.pdf

# видео: проверка движения, контрольные кадры, черновик, финал
blender -b --python scripts/walkthrough.py -- route.json --analyze
blender -b --python scripts/walkthrough.py -- route.json --stills --res 480 --samples 8
blender -b --python scripts/walkthrough.py -- route.json --res 960 --samples 32 --name draft
blender -b --python scripts/walkthrough.py -- route.json --engine cycles --res 1280 --samples 96 --name final
```

Форматы конфигов описаны в начале каждого скрипта.

## Время рендера

Замерено на Mac с M4 Pro (20-ядерная видеокарта), Cycles на Metal, kernel optimization выключен:

| Режим | Параметры | На кадр |
|---|---|---|
| Предпросмотр | 640–800 px, 24–32 сэмпла | 2–5 с |
| Стандарт | 1600 × 1200, 256 сэмплов | ~70 с |
| Высокое | 2560 × 1920, 512 сэмплов | ~6 мин |
| 4K | 3840 × 2880, 1024 сэмпла | ~25 мин |
| Видео, черновик | EEVEE 960 × 540 | ~1,5 с |
| Видео, финал | Cycles 1280 × 720, 96 сэмплов | ~11 с |

## Какие проблемы скилл обходит

- Падение Blender 5.2 на Metal при компиляции специализированных ядер (`kernel_optimization_level = OFF`).
- Чёрные пятна на потолке из-за перекрывающихся плоскостей.
- Чёрное стекло в душе и окнах (Fresnel на обратной стороне тонкого стекла).
- Искажённые скругления на масштабированных объектах, голубоватая текстура льна, area-лампы в кадре чёрными прямоугольниками.
- Дёрганая камера в видео (резкие повороты, остановки в каждой точке, нет размытия в движении).

Подробно: [`references/pitfalls.md`](references/pitfalls.md).

## Ограничения

- Мебель, которую Claude собирает из простых форм, и модели из каталога планировщика на 4K выглядят упрощённо.
  Для рендеров высокого уровня сначала замените ключевые предметы детальными моделями.
- Правила по именам объектов в `references/planner_objects.md` написаны для GLB-экспорта одного онлайн-планировщика.
  Другие источники тоже работают, но объекты Claude будет разбирать заново.
